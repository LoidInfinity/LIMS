# PPT 大纲与版式

输入示例：

```json
{
  "slides": [
    {"title": "研究问题", "bullets": ["为什么需要这项研究", "已有证据与缺口"], "caption": "课题组例会"},
    {"title": "结果与解释", "bullets": ["只陈述数据支持的结论"], "image": "chart.png", "caption": "数据来源与单位"}
  ]
}
```

标题必填，bullets、image、caption 可选。image 是相对于大纲 JSON 的本地 PNG/JPEG 路径；不拉伸、不重着色，等比放入可用区域。有文字和图片时分栏，无文字时图片居中。使用标题和正文占位符，文本可编辑。

画布、边距、字号、颜色全部读取风格。标题最多估计两行，说明最多两行；内容区按字体大小和中西文宽度估计容量，长列表分页，单条过长报错。分页重复图和说明，不丢内容。该估计不是字体排版引擎，实际换行仍需 PowerPoint/LibreOffice 渲染验收。

同一套风格不意味着图表的 10 pt 与 PPT 正文的 20 pt 相同：跨媒介共享字体、颜色，字号按各自角色配置。没有安装字体时不可保证视觉一致。内嵌图片的文字和颜色不会随 PPT 的风格自动改变，应先以同版配置重新生成图表。
